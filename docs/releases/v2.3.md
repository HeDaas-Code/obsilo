# Obsilo Agent v2.3

**2.3.1 至 2.3.6 版本**，于 2026 年 4 月发布。

将重复性任务的 token 成本降低高达 90%，全面改革了记忆和自主学习系统，并修复了 ONNX 排序器和隐式连接的关键问题。

## Token 成本降低 (EPIC-018)

诸如"搜索我的康德笔记并撰写摘要"这类标准任务，以前在 8 次 LLM 迭代中消耗 634,000 个输入 token，每次执行成本约 2 美元。在 GitHub Copilot 的 168k 上下文限制下，代理会直接崩溃。发布此版本后，相同任务仅使用约 60,000 个 token，迭代 2-3 次，成本约 0.15 美元。

### 快速路径执行 (ADR-061)

当代理曾经解决过同类任务时，可以跳过迭代式 ReAct 循环，转而执行预先计划好的工具序列。

- 配方匹配通过关键词评分检测已知任务模式，备选方案为描述匹配
- 单次 planner LLM 调用根据匹配的配方生成具体的执行计划
- 计划确定性执行：第一阶段并行搜索工具，第二阶段并行读取工具，然后进行 1-2 次常规循环迭代用于展示
- 防护栏：每个阶段设置硬性允许列表（仅搜索、仅读取），至少 3 次成功使用后才能获得资格，非法计划时回退到常规循环
- 所有工具调用仍需经过治理管道进行审批检查和日志记录

### KV 缓存优化的提示结构 (ADR-062)

系统提示现在按稳定性排序，以最大化跨迭代的 KV 缓存命中。

- 稳定部分（模式定义、工具描述、规则、安全边界）位于第 1-8 位，在会话内的所有迭代中被缓存
- 动态部分（技能、记忆、配方、保险库上下文）位于第 9-16 位
- 时间戳从第 1 位移至第 16 位，修复了每次 API 调用都会使整个缓存失效的 bug
- 最近锚点（将当前任务列表附加为最后的用户消息）补偿技能指令 primacy 降低的影响

### 上下文外部化 (ADR-063)

大型工具结果不再积累在对话历史中。

- 超过 2,000 字符的结果写入临时文件，历史中仅保留紧凑引用
- 工具特定的引用格式：搜索结果显示前 5 个匹配项，语义搜索显示前 3 个匹配项及评分，read_file 显示标题和预览
- 确定性的文件路径（无时间戳）保持 KV 缓存兼容性
- 仅追加历史：外部化在结果创建时发生，而非事后追溯
- 任务完成后自动清理，插件启动时进行孤儿清理

## 记忆和学习改进 (ADR-058, 059, 060)

### 语义配方提升 (ADR-058)

配方提升从基于序列切换为基于意图匹配。之前的系统比较精确的工具序列，但这从未有效过，因为 LLM 是非确定性选择工具的。新系统使用与知识层相同的嵌入模型，通过余弦相似度比较用户消息。

### 预算感知的长期记忆 (ADR-059)

长期记忆提取器现在将 800 字符预算作为硬性约束。每个条目带有 `[YYYY-MM]` 最近标记。当新信息超出预算时，提取器会删除或压缩最不相关的条目，而不是让文件超过可见窗口。

### 会话摘要可靠性 (ADR-060)

修复了一个 bug：会话摘要被写入数据库但从未被读取回来。MemoryRetriever 现在直接查询数据库，而不是查找从未创建过的旧 `.md` 文件。

## Electron 中的 ONNX 排序器 (FIX-07b)

本地排序器（知识管道第 4 阶段）从未工作过，因为 transformers.js 检测到 Electron 是 Node.js 并选择了 `onnxruntime-node`，其原生插件无法在渲染器进程中加载。三项更改修复了此问题：

- esbuild 插件将 `IS_NODE_ENV` 补丁到 `false`，影响 transformers.js 的后端选择，强制使用 web/WASM 分支
- WASM 二进制文件（`ort-wasm-simd-threaded.wasm`，12 MB）复制到插件目录并从磁盘预加载，避免从 CDN 获取
- RerankerService 接受 `pluginAbsDir` 以实现可靠的 WASM 路径解析

一次性失败保护防止 ONNX 失败后重复重试 (FIX-07)。

## Google Gemini 作为专用提供者 (ADR-064)

Google Gemini 现在与 Anthropic、OpenAI 等并列作为一级提供者。以前，用户必须将 Gemini 配置为"自定义"提供者并手动设置基础 URL，这对非技术用户容易出错。

- **专用提供者类型：** 在提供者下拉菜单中选择"Google Gemini"，输入您的 API 密钥，完成
- **免费层级入门：** 设置向导提供 Gemini 2.5 Flash 作为免费层级选项，并附带从 Google AI Studio 获取 API 密钥的分步说明
- **CORS 绕过：** 用于 Electron 渲染器进程的自定义 Node.js fetch 包装器，因为 `globalThis.fetch` 被 Google API 端点的 CORS 阻止
- **模型获取：** 直接从设置 UI 浏览可用的 Gemini 模型（剥离 Google 的 `models/` 前缀以实现 OpenAI 兼容用法）
- **内置模型：** 预配置 Gemini 2.5 Flash 和 Gemini 2.5 Pro，以及带有上下文窗口和功能元数据的完整模型注册表
- **迁移：** 现有的自定义 Gemini 配置会自动迁移到专用提供者类型

## Bug 修复

- **ImplicitConnections 竞态条件 (FIX-08):** 数据库可能在异步计算期间关闭，导致"语句已关闭"错误。`isOpen()` 保护防止 `computeAll()` 在已关闭的数据库上运行。
- **ChatLink YAML 解析错误 (FIX-11):** 链接笔记中格式错误的 YAML frontmatter 现在会被简洁记录，笔记被跳过而非崩溃。
- **学习配方强制启用 (FIX-10):** 配方学习现在始终处于激活状态（UI 切换从未连接）。
- **Rollup darwin-arm64:** 将 `@rollup/rollup-darwin-arm64` 移至 optionalDependencies 以修复 Linux 运行器上的 CI 构建。
- **错误处理程序 lint:** 修复了 FastPath 错误处理程序回调中的 `require-await` lint 错误。
- **历史面板竞态条件:** 聊天历史按钮在 Obsidian 启动后不起作用，因为侧边栏视图在异步插件初始化完成前就打开了。历史面板现在在首次点击时延迟初始化。
- **Gemini 入门提供者类型:** 免费层级入门流程错误地将提供者类型设置为"custom"而非"gemini"，导致首次使用时出现 CORS 失败。
- **URL 子字符串清理 (CodeQL #65):** Gemini 迁移代码在未解析的 URL 上使用 `includes()` 来检测 Google API 端点，这可能匹配主机名出现在路径或查询字符串中的 URL。替换为正确的 URL 解析和主机名比较 (CWE-20)。
- **提供者标签 lint 合规性 (PR #11394):** 将品牌名称提供者标签（Google Gemini、LM Studio、GitHub Copilot 等）从 i18n 区域设置模块移至静态常量文件。Obsidian 审查机器人标记了针对 sentence-case 规则的 `eslint-disable` 指令为不允许，而且品牌名称本身不能小写。将它们从区域设置文件中提取出来可解决这两个约束。
