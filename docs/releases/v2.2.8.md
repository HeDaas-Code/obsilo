# Obsilo Agent v2.2.8

本次更新新增了 **MCP 连接器**以支持 Claude Desktop 和远程 AI 助手、**统一知识层**（基于 SQLite 的向量搜索、本地重排序）和**安全加固**。大规模重构在添加重要新功能的同时，代码库减少超过 7,500 行。

## 新功能

### MCP 服务器：连接 Claude Desktop 和远程 AI

Obsilo 作为 MCP（模型上下文协议）服务器运行，允许 Claude Desktop 等外部 AI 助手与您的保险库进行交互。

- **本地连接器：** 通过 stdio 代理集成 Claude Desktop 的 localhost HTTP 服务器
- **远程中继：** 基于 Cloudflare Workers 的中继服务，支持 claude.ai、ChatGPT 等远程客户端
- **6 个 MCP 工具：** `get_context`、`search_vault`、`read_notes`、`write_vault`、`sync_session`、`update_memory`
- **自动会话跟踪：** MCP 对话自动出现在 Obsilo 的聊天历史中
- **中继设置向导：** 一键部署个人中继工作线程
- **Bearer 令牌认证：** 自动生成的本地服务器安全令牌
- **Cloudflare Tunnel 支持：** 通过 `cloudflared` 可选公共端点

### 统一知识层

基于 SQLite 重构语义搜索，提升性能和检索质量。

- **KnowledgeDB：** 基于 SQLite 的存储（通过 sql.js），取代之前的 JSON 文件方案
- **VectorStore：** 统一向量索引，支持余弦相似度搜索
- **图谱扩展：** 追踪 wikilinks 和内容地图属性，发现相关笔记（1-3 跳可配置）
- **隐式连接：** 自动发现无直接链接但语义相似的笔记
- **本地重排序：** 设备端跨编码器模型（ms-marco-MiniLM via WASM）对搜索结果重新评分，提升质量
- **上下文检索：** 可选的 LLM 生成的块上下文丰富（搜索质量提升 49-67%）

### 存储整合

所有插件数据现统一存放在结构化位置。

- **统一存储：** 全局数据位于 `~/.obsidian-agent/`，保险库特定数据位于 `.obsidian/plugins/obsilo-agent/`
- **自动迁移：** 首次加载时迁移旧存储位置的数据
- **MemoryDB：** 剧集、食谱和模式从独立 JSON 文件迁移到 SQLite

## 安全

安全审计发现并修复了 6 个高严重性问题：

- **MCP 服务器认证：** Bearer 令牌 + 受限 CORS + 1MB 请求体大小限制
- **MCP 治理层：** 路径遍历防护、IgnoreService 强制执行、configDir 保护和所有 MCP 操作的审计日志
- **权限自我提权被阻止：** 代理无法再静默更改自动审批设置；现在会显示审批卡片
- **备份导出净化：** API 密钥和令牌在导出前被剥离
- **工具输入模式验证：** 所有工具参数在执行前根据声明的模式进行验证
- **依赖修复：** path-to-regexp、lodash-es 和 brace-expansion 漏洞已修复

## 重构与性能

- **代码行数减少 7,564 行：** 大规模清理，移除死代码、未使用的导入和渲染开销
- **UI 组件提取：** SuggestionBanner 和 OnboardingFlow 从单体 AgentSidebarView 中提取
- **ModeService 优化：** 更快的初始化、更低的内存占用
- **Windows 和 Linux 兼容性：** 平台感知的二进制发现、环境变量和路径处理

## 文档

- 新增文档网站（VitePress）
- 所有功能的德语文档
- 架构文档更新（arc42、ADR）

## 破坏性变更

- **MCP 客户端必须认证：** 现有 MCP 集成（Claude Desktop）通过 stdio 代理工作线程自动重连，从 `~/.obsidian-agent/mcp-token` 读取令牌。手动 HTTP 客户端需要 `Authorization: Bearer <token>` 头。
- **备份格式：** 导出的备份不再包含 API 密钥。将 v2.2.8 备份导入旧版本将导致 API 密钥字段为空。
- **存储迁移：** 首次启动时迁移旧存储位置。这是自动的但单向的。降级到 v2.2.7 需要手动恢复数据。
